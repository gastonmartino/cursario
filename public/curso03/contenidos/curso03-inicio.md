# Usuario con "U" de utopía

## *El usuario es una ficción*
El usuario se construye como una narrativa, un arquetipo, una ficción útil. Es útil porque permite enfocar una investigación o diseñar una interacción. Pero se vuelve problemática cuando:
- representa a una persona promedio;
- oculta la diversidad de situaciones;
- ignora a quienes quedan fuera;
- separa artificialmente al usuario del sistema que lo condiciona;
- deja fuera los costos materiales y ambientales.

 
## *¿Por qué seguir llamándolo usuario?*
El usuario no es simple operador de palancas y perillas que interactúa para conseguir algo del sistema. La palabra usuario reduce la experiencia al momento del uso.
